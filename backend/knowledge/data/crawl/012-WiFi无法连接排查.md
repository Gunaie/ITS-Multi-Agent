# WiFi无法连接排查指南

## 故障现象

笔记本网络连接问题在售后中高频出现,常见表现:
- WiFi列表为空,搜索不到任何无线网络
- 能看到WiFi但无法连接,提示无法连接到此网络
- 连接后频繁断开,网络不稳定
- 显示已连接但无法上网(无Internet)
- 连接需要输入密码但总是提示密码错误

## 可能原因

1. **无线网卡驱动问题**:驱动损坏、未安装、版本不兼容
2. **WiFi开关未开启**:物理开关或功能键关闭了无线网卡
3. **系统网络服务异常**:WLAN AutoConfig服务停止
4. **路由器问题**:路由器故障、信号弱、DHCP分配异常
5. **IP地址冲突或获取失败**:DHCP获取IP失败
6. **网络配置错误**:DNS设置异常、代理设置错误
7. **硬件故障**:无线网卡损坏或天线脱落

## 排查步骤

### 第一步:确认WiFi已开启
1. 查看任务栏WiFi图标是否显示
2. 点击网络图标,确认WiFi开关已打开
3. 部分机型有物理WiFi开关或按键(如Fn+F5),确认已开启
4. 检查飞行模式是否误开启(设置 → 网络和Internet → 飞行模式)

### 第二步:确认是否为路由器问题
1. 用手机或其他设备连接同一WiFi测试
2. 若其他设备也无法连接,问题在路由器:
   - 重启路由器(拔电源30秒后重新通电)
   - 检查路由器是否正常工作(指示灯)
3. 若其他设备正常,问题在本机

### 第三步:重启网络和电脑
1. 设置 → 网络和Internet → 状态 → 网络重置
2. 此操作会重置所有网络适配器并重启电脑(5分钟后自动重启)
3. 或手动重启电脑后再次尝试连接

### 第四步:检查无线网卡驱动
1. 右键开始菜单 → 设备管理器 → 网络适配器
2. 找到无线网卡(名称含Wireless、WiFi、WLAN、802.11)
3. 查看:
   - 是否有黄色感叹号
   - 是否被禁用(右键 → 启用设备)
   - 是否在列表中(若无,可能驱动未安装)
4. 右键 → 卸载设备(勾选删除驱动),重启后重装驱动

### 第五步:重装无线网卡驱动
1. 从笔记本品牌官网下载对应型号的无线网卡驱动
2. 若无法联网:
   - 用手机USB共享网络给电脑
   - 或用网线连接下载无线驱动
3. 安装驱动后重启电脑
4. 重新尝试连接WiFi

### 第六步:检查网络服务
1. 按 `Win+R`,输入 `services.msc` 回车
2. 找到"WLAN AutoConfig"服务
3. 确认状态为"正在运行",启动类型为"自动"
4. 若已停止,右键 → 启动
5. 同样检查"Wired AutoConfig"和"Windows Firewall"服务

### 第七步:重置网络协议
1. 管理员命令提示符依次运行:
   ```
   netsh winsock reset
   netsh int ip reset
   ipconfig /release
   ipconfig /renew
   ipconfig /flushdns
   ```
2. 重启电脑后重新连接WiFi

## 常见问题处理

### 已连接但无法上网
1. 设置 → 网络和Internet → 状态 → 更改适配器选项
2. 右键WiFi → 属性 → Internet协议版本4(TCP/IPv4)
3. 确认选择"自动获得IP地址"和"自动获得DNS服务器地址"
4. 清除代理设置:设置 → 网络和Internet → 代理 → 关闭代理

### 频繁断开
1. 设备管理器 → 无线网卡属性 → 电源管理
2. 取消"允许计算机关闭此设备以节约电源"
3. 更新无线网卡驱动到最新版
4. 检查路由器是否过热或固件需要更新

### 提示密码错误但密码正确
1. 确认输入法未开启全角或中英文标点
2. 忘记网络后重新连接(设置 → 网络 → 管理已知网络 → 忘记)
3. 重启路由器
4. 路由器端修改WiFi密码后重新连接

### 仅特定WiFi无法连接
1. 在路由器端确认MAC地址过滤未阻止本机
2. 路由器信道问题:登录路由器管理页面更换信道
3. 路由器加密方式不兼容:更换为WPA2-PSK

## 何时联系售后

- 重装驱动后仍搜索不到任何WiFi
- 设备管理器中无线网卡完全消失
- 怀疑无线网卡硬件损坏或天线脱落
- 多个网络环境均无法连接
- 设备在保修期内

## 预防建议

- 保持无线网卡驱动为官网推荐版本
- 不要随意关闭WLAN AutoConfig服务
- 定期重启路由器保持稳定
- 避免安装多个网络管理软件冲突
- 系统更新时留意是否影响网络驱动
