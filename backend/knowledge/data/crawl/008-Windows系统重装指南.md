# Windows系统重装指南

## 适用场景

当系统出现以下问题时,重装系统是有效的解决方案:
- 系统频繁蓝屏、崩溃,无法正常使用
- 系统文件损坏,sfc和DISM无法修复
- 中毒后系统异常,杀毒无法彻底清除
- 系统臃肿卡顿,优化无效
- 想要从旧版本升级或降级Windows版本

## 重装前准备(重要)

### 第一步:备份重要数据
1. 将桌面、文档、下载文件夹中的重要文件复制到U盘或外接硬盘
2. 备份浏览器书签(导出HTML文件)
3. 记录已安装软件的授权码和账号信息
4. 备份微信/QQ聊天记录(如有需要)
5. 导出邮箱账号和密码
6. **重装会清除C盘所有数据,务必确认备份完整**

### 第二步:准备安装介质
1. 准备一个8GB以上的U盘(会被格式化,提前转移数据)
2. 在另一台正常电脑上,访问微软官网下载"媒体创建工具"(Media Creation Tool)
3. 运行工具,选择"为另一台电脑创建安装介质"
4. 选择对应的Windows版本(家庭版/专业版)和架构(64位)
5. 选择U盘作为介质,等待制作完成(约15-30分钟)

## 重装步骤

### 方法一:U盘启动重装(推荐,适用于无法进入系统)

1. **设置U盘启动**
   - 将制作好的U盘插入笔记本
   - 开机时按启动菜单键(常见为F12、F11、F8或Esc,视品牌而定)
   - 在启动菜单中选择U盘(带有UEFI前缀的选项)

2. **进入安装界面**
   - 选择语言、时间、键盘格式,点击下一步
   - 点击"现在安装"
   - 输入产品密钥(若无,点击"我没有产品密钥",安装后激活)

3. **选择版本和许可**
   - 选择要安装的Windows版本(需与原系统或密钥匹配)
   - 接受许可条款

4. **磁盘分区(关键步骤)**
   - 选择"自定义:仅安装Windows"
   - 若想全新安装,可删除所有分区后新建(会清除所有数据)
   - 若保留其他盘数据,只删除C盘所在分区
   - 选择目标分区,点击下一步开始安装

5. **等待安装完成**
   - 安装过程约15-30分钟,期间会自动重启数次
   - 按提示完成初始设置(账户、网络、隐私选项)

### 方法二:系统内重置(系统可正常进入时)

1. **打开重置功能**
   - 设置 → 更新和安全 → 恢复
   - 在"重置此电脑"下点击"开始"

2. **选择重置选项**
   - "保留我的文件":保留个人文件,移除应用和设置
   - "删除所有内容":清除所有数据,完全重置(推荐彻底重装时使用)

3. **选择重置方式**
   - "云下载":从微软服务器下载系统(需联网,约4GB流量)
   - "本地重新安装":使用本机预装文件重置

4. **确认并重置**
   - 按提示确认选项,点击"重置"
   - 等待重置完成(约30-60分钟)

## 重装后必做事项

### 第一步:安装驱动
1. 连接网络,让Windows自动安装基础驱动
2. 从笔记本品牌官网下载对应型号的官方驱动包
3. 按顺序安装:芯片组 → 显卡 → 声卡 → 网卡 → 其他
4. 重启后检查设备管理器是否有未识别设备

### 第二步:系统更新
1. 设置 → 更新和安全 → Windows更新
2. 检查并安装所有重要更新
3. 多次检查直到提示"已是最新"

### 第三步:安装必要软件
1. 安装安全软件(Windows Defender已足够,或第三方杀毒)
2. 安装常用软件(浏览器、办公软件、解压工具等)
3. 恢复备份的个人文件

### 第四步:激活系统
1. 若重装前已激活数字许可证,联网后会自动激活
2. 设置 → 更新和安全 → 激活,查看激活状态
3. 若未自动激活,输入产品密钥手动激活

## 常见问题处理

### U盘无法启动
- 进入BIOS(F2或F1),关闭"安全启动"(Secure Boot)
- 将启动模式设置为UEFI
- 重新制作U盘启动盘

### 安装时提示找不到硬盘
- 多为RAID/ACHI模式问题
- 在安装界面按Shift+F10打开命令提示符
- 或在BIOS中将存储模式从RAID改为AHCI

### 安装后无法联网
- 优先用网线连接,安装网卡驱动
- 或用手机USB共享网络下载网卡驱动

## 何时联系售后

- 多次重装失败,安装过程中频繁报错
- 重装后仍蓝屏(可能是硬件问题)
- BIOS设置异常无法启动安装
- 设备仍在保修期内,不熟悉操作可送售后协助

## 注意事项

- 重装前务必确认数据已备份,数据丢失无法恢复
- 使用微软官方工具制作安装盘,不要用来历不明的Ghost系统
- 记录原系统版本和激活方式,避免激活问题
- 重装是最后手段,可尝试系统还原或重置后再考虑全盘重装
