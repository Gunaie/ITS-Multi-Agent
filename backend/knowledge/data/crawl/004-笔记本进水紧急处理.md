# 笔记本进水紧急处理指南

## 紧急程度说明

笔记本进水属于**紧急故障**,处理是否及时直接决定设备能否修复。液体接触主板后会快速腐蚀电路,必须在第一时间采取正确措施。**错误的处理方式(如尝试开机)会造成更严重的损坏。**

## 故障现象

- 不慎将水、茶、咖啡、饮料等液体泼溅到键盘或机身上
- 进水后屏幕闪烁、花屏、突然黑屏
- 进水后无法开机、按键失灵
- 进水后闻到烧焦味或听到异响

## 紧急处理步骤(黄金5分钟)

### 第一步:立即断电(最关键)
1. **立即长按电源键强制关机**,不要走正常关机流程
2. 若电源键已无反应,直接拔掉电源适配器
3. 若为可拆卸电池机型,立即取出电池
4. **切勿尝试开机查看是否正常** — 通电瞬间可能造成主板短路烧毁

### 第二步:倒置排水
1. 迅速将笔记本屏幕合上(若屏幕未进水)
2. 将笔记本倒置(键盘朝下),让液体从键盘缝隙流出
3. 用干毛巾或纸巾吸干表面液体
4. 保持倒置姿势至少5-10分钟,让残余液体流出

### 第三步:断开外接设备
1. 拔掉所有USB设备、鼠标、电源线、网线
2. 取出SD卡、SIM卡等可拆卸部件
3. 若外接了显示器,断开连接

### 第四步:清理表面液体
1. 用吸水性好的纸巾或超细纤维布吸干键盘和机身表面液体
2. 轻轻倾斜笔记本,让缝隙中的液体流出
3. **切勿用力甩动**,避免液体扩散到更多区域
4. 用棉签清理键盘缝隙、接口处的残余液体

## 不同液体的处理差异

### 清水
- 危害相对较小,完全晾干后可能恢复正常
- 需静置晾干至少48-72小时

### 茶水/咖啡/含糖饮料
- 含糖分和酸性物质,会腐蚀电路板
- 即使晾干后糖分残留仍会持续腐蚀
- 建议尽快送售后拆机清洗主板

### 酒性饮料/带电液体
- 可能含有酒精等导电成分
- 腐蚀性强,需专业清洗
- 进水后即使能开机也建议送修检测

## 干燥处理方法

### 自然晾干(推荐)
1. 将笔记本打开成倒V字形(屏幕和键盘呈90-120度角)
2. 放置在通风良好、干燥的环境中
3. **至少静置48-72小时**,确保完全干燥
4. 切勿用吹风机热风吹 — 高温会熔化键盘和外壳

### 干燥剂辅助
1. 将笔记本与干燥剂(硅胶包)一起放入密封箱
2. 干燥剂可加速吸湿,缩短干燥时间
3. 注意干燥剂不要直接接触液体残留

## 绝对不能做的事

- **切勿尝试开机** — 通电即可能短路烧毁主板
- **切勿用吹风机热风吹** — 高温会熔化塑料部件和键盘
- **切勿用力甩动** — 液体会扩散到更多区域
- **切勿拆机自行清理主板** — 操作不当会造成二次损坏,且影响保修
- **切勿等待"自然风干一晚"后立即开机** — 内部可能仍未干透

## 何时联系售后

### 建议立即送修的情况
- 进水量较大,液体渗入机身内部
- 进的是含糖饮料、咖啡、酒等腐蚀性液体
- 进水时设备处于开机状态,已出现异常
- 闻到烧焦味或看到冒烟
- 设备仍在保修期内(进水一般不在保修范围,但官方清洗更安全)

### 送修前准备
1. 提前备份(若硬盘可拆卸,可取出硬盘在其他设备读取数据)
2. 如实告知售后进水情况和已采取的处理措施
3. 进水时间越短送修,修复成功率越高

## 修复可能性评估

- **清水少量进水,及时断电干燥**:修复概率高,可能完全恢复
- **含糖饮料进水,及时断电并送修清洗**:修复概率中等
- **进水后仍开机使用,或延迟送修**:修复概率低,主板可能已严重腐蚀
- **进水冒烟或有烧焦味**:主板已烧毁,需更换主板,成本较高

## 预防建议

- 使用笔记本时远离水杯和饮料
- 为笔记本配备键盘保护膜(注意可能影响散热)
- 不要在潮湿环境中使用和存放
- 为意外损坏购买延保或意外险(进水通常需付费维修)
