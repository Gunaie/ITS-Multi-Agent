# 保修政策与售后网点查询指南

## 保修政策概述

联想产品提供全国联保服务,主要保修政策如下:

### 标准保修期
- **笔记本电脑**:整机保修1年(部分商务机型主板保修2-3年)
- **台式机**:整机保修1-3年(视机型而定)
- **平板设备**:整机保修1年
- **电池**:属消耗品,保修1年
- **电源适配器**:保修1年
- **服务器/工作站**:通常3年上门服务

### 保修起始时间
- 保修期自购买之日(发票日期)起计算
- 无发票情况按出厂日期计算(可能短于实际购买时间)
- 建议保留购买发票或电子凭证

## 保修范围说明

### 保修包含
- 正常使用下出现的硬件故障
- 制造缺陷导致的故障
- 主板、CPU、内存、硬盘、屏幕等主要部件
- 键盘、触摸板等部件(部分消耗品除外)

### 保修不包含(需付费维修)
- **人为损坏**:进水、跌落、挤压、划伤
- **意外损坏**:雷击、火灾、自然灾害
- **私自拆机**:自行拆卸导致的损坏
- **非原厂配件**:使用非官方配件导致的故障
- **外观损伤**:外壳划痕、屏幕坏点(超过行业标准)
- **软件问题**:系统故障、病毒、数据丢失
- **进水/液体泼溅**:属于人为损坏,不在免费保修范围
- **超出保修期**:需付费维修

## 查询保修状态

### 在线查询方式
1. 访问联想官方服务网站
2. 输入设备序列号(SN码)查询保修状态
3. SN码位置:
   - 笔记本底部贴纸
   - 原包装箱标签
   - BIOS信息(开机按F2查看)
   - 部分机型电池仓内

### 查询内容
- 保修起止日期
- 保修类型(上门/送修)
- 主要部件保修状态
- 是否有延保服务

## 售后服务网点查询

### 查询途径
1. **官方网站查询**:联想官网服务支持页面,输入城市或定位查询附近服务网点
2. **官方服务热线**:拨打联想客服电话,人工查询附近授权服务网点
3. **官方微信公众号**:关注联想服务公众号,在线查询网点
4. **官方App**:联想官方App内置服务网点查询功能

### 网点类型
- **联想官方服务中心**:联想直营或授权服务中心,提供全面维修服务
- **授权服务站**:提供基础维修和检测服务
- **送修服务点**:接收设备送至维修中心
- **上门服务**:部分商务机型提供上门维修

### 网点选择建议
- 优先选择联想官方服务中心(服务更全面)
- 查询网点是否支持对应产品类型(部分网点仅服务特定产品线)
- 确认网点营业时间,避免白跑
- 复杂维修建议提前电话确认是否可现场处理

## 送修前准备

### 资料准备
1. 购买发票或电子凭证(证明购买日期)
2. 保修卡(若有)
3. 设备序列号(SN码)记录
4. 身份证(部分网点需要登记)

### 数据备份
1. **重要数据必须备份**:维修可能涉及重装系统或更换硬盘
2. 桌面、文档、下载文件夹的文件
3. 浏览器书签和密码
4. 重要软件的授权信息
5. 维修可能导致数据丢失,官方不承担数据丢失责任

### 设备准备
1. 记录故障现象和出现时间
2. 拍摄设备外观照片(避免外观争议)
3. 取出SIM卡、SD卡、USB接收器等
4. 携带电源适配器(部分故障需现场测试)
5. 取出 BIOS 密码(告知工作人员)

## 维修流程

### 送修流程
1. 到网点登记故障现象
2. 工程师检测确认故障
3. 保修期内非人为损坏:免费维修
4. 非保修或人为损坏:报价确认后付费维修
5. 维修完成通知取机
6. 取机时当场验收功能正常

### 维修时长
- 简单故障(如重装系统):当天可取
- 常见硬件维修:1-3个工作日
- 需调件维修:3-7个工作日
- 复杂主板维修:可能1-2周

### 维修后注意
1. 索要维修单据和保修凭证
2. 确认维修部件的保修期(维修件通常保修3-6个月)
3. 当面测试功能是否正常
4. 核对设备序列号避免调换

## 延保服务

### 延保类型
- 整机延保:延长主要部件保修期
- 意外损坏保护:覆盖进水、跌落等意外(需购买)
- 上门服务延保:延长上门服务期

### 购买建议
- 商务机型建议购买延保
- 高价值设备建议购买意外险
- 延保需在原保修期内购买

## 常见问题

### 保修期内被要求付费
- 确认故障是否属于人为损坏
- 对检测结果有异议可要求复检或联系官方客服
- 进水、跌落等确实属于人为损坏

### 异地维修
- 联想全国联保,可在全国任意官方网点维修
- 携带购买凭证和保修卡

### 维修后同一故障复发
- 维修部件有保修期(通常3-6个月)
- 在保修期内同一故障可免费再修

## 注意事项

- 维修前务必备份数据,官方不承担数据丢失责任
- 保修认定以官方检测为准
- 切勿自行拆机,影响保修
- 保留所有维修单据以备查询
- 具体保修政策和联系方式以联想官方最新公示为准
