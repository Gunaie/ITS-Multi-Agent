# 联想售后多智能体系统实现指南

本手册旨在指导新人从零开始一步步搭建并运行"联想售后与技术支持智能客服系统"。

## 1. 环境准备

### 1.1 基础软件安装
- **Python 3.10+**: 建议使用 `uv` 管理虚拟环境。
- **Node.js 16+**: 用于运行 Vue 3 前端。
- **MySQL 8.0**: 存储用户信息与基础数据。
- **Redis**: 存储分布式会话与元数据。

### 1.2 获取 API 密钥
- **阿里百炼**: 获取 `AL_BAILIAN_API_KEY`。
- **百度地图**: 注册开发者并获取 `BAIDU_MAP_AK`（需开启地理编码、周边搜索、路网计算权限）。
- **LangSmith**: 获取追踪密钥以开启可观测性。

---

## 2. 后端核心模块实现

### 第一步：搭建知识库 RAG 引擎 (`backend/knowledge`)
1. **数据解析**：编写脚本读取 `data/crawl` 中的 Markdown 文件。
2. **向量入库**：使用 `ChromaDB` 和百炼的 Embedding 模型完成数据向量化。
3. **混合检索逻辑**：
   - 使用向量检索获取语义相关的片段。
   - 使用 `Jieba` 进行关键词匹配以增强专有名词的命中率。
4. **API 暴露**：使用 FastAPI 暴露 `/query` 接口。

### 第二步：智能体编排层实现 (`backend/app`)
1. **定义智能体**：
   - **调度专家 (Orchestrator)**：负责意图识别。
   - **技术专家 (Technical Agent)**：绑定知识库工具和 MCP 搜索。
   - **服务专家 (Service Agent)**：绑定百度地图工具。
2. **任务交接 (Handoff)**：配置智能体间的跳转逻辑，确保持续对话的上下文不丢失。
3. **工具集成**：
   - 实现 `baidu_map_tool.py`，对接百度 REST API。
   - 对接 `mcp_servers.py`，接入联网搜索能力。

### 第三步：分布式会话管理
1. **Redis 集成**：使用 Redis 存储序列化后的 `Session` 对象。
2. **SSE 流式输出**：实现 `chat_stream` 接口，通过生成器实时推送 `raw_response_event` 给前端。

---

## 3. 前端界面开发 (`front`)

### 第一步：咨询平台 (Agent UI)
1. **组件开发**：实现聊天气泡、思考过程下拉框、Markdown 渲染。
2. **位置服务**：集成浏览器 Geolocation API（WGS-84），按定位契约携带坐标系前缀发送
   （`location: "wgs84:{lat},{lng}"`），后端自动转换为百度坐标系；纯文本地点直接传原文即可。

### 第二步：管理平台 (Knowledge UI)
1. **文档管理**：实现上传、切分预览功能。
2. **会话管理**：实现历史记录的删除与标题编辑（对接后端的 Redis 接口）。

---

## 4. 系统集成与优化

1. **并行化改造**：将工具调用中多次串行的 API 请求改为 `asyncio.gather` 或批量接口调用。
2. **监控接入**：配置 LangSmith，观察 Trace 链路以优化 Prompt。
3. **量化评估**：运行 `tests/evaluation/rag_eval.py`，根据 Ragas 指标调整检索参数。

---

## 5. 启动与测试
1. 修改根目录下的 `.env` 文件。
2. 运行 `python scripts/start_dev.py`。
3. 访问咨询平台，测试“附近维修站”和“电脑开机故障”两个核心场景。
