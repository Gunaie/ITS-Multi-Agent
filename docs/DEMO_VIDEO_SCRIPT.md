# Demo 演示视频脚本

> 目标：5-10 分钟完整展示「联想售后多智能体客服系统」的核心能力——多 Agent 三分支编排、知识库 RAG、联网搜索、定位+网点查询、知识库管理平台。
> 演示地址：客服端 http://47.102.212.208:8000 ｜ 管理平台 http://47.102.212.208:8100

## 一、录制前准备（必做）

### 1. 环境与工具
- [ ] 录屏软件：**OBS Studio**（免费，推荐）或 Win+G（Xbox Game Bar，仅录单个浏览器窗口）
- [ ] 分辨率 1080p，浏览器缩放 **100%**，窗口最大化
- [ ] 使用**无痕窗口**（Ctrl+Shift+N）录制，避免浏览器插件/历史/自动填充入镜
- [ ] 关闭无关通知（微信/邮件），桌面壁纸干净
- [ ] 输入法切中文，提前想好打字内容（脚本里每个问题都可直接复制粘贴，粘贴比打字快且无错字）

### 2. 数据与账号彩排（关键！）
- [ ] **彩排账号**：提前注册一个账号，把下面每个问题都问一遍（预热 LLM + 确认服务正常）
- [ ] **正式账号**：录制时注册全新账号（如 `demo0904`），每个场景用**新建会话**——系统 temperature=0 会模仿会话历史，复用旧会话可能出现奇怪行为
- [ ] 彩排确认：百炼额度正常（问一句话能秒回）、服务器容器全部 Up
- [ ] **百度 AK 配额只有 100 次/天**：网点查询场景每天只录 1-2 次，彩排时别反复测定位；若当天返回配额超限，网点查询会退化到数据库兜底（仍能展示网点名称/电话，只是没有距离和地图测距），不影响主体演示
- [ ] 准备上传用的测试文档：新建一个 `联想拯救者Y9000P清灰维护指南.md`，内容写 5-8 条清灰步骤/注意事项（管理平台上传环节用）

### 3. 预期节奏说明
- 技术问答（RAG 生成）回答约 **30-90 秒**（思考模型逐字流式输出，这是"AI 在认真检索"的真实表现，剪辑时可 2-3 倍速加速等待部分，保留回答开头和结尾）
- 服务类短问答 **1-3 秒**返回（业务专家是快模型，可强调响应速度）

## 四、风险与备用话术

| 风险 | 现象 | 备用处理 |
|---|---|---|
| 百炼额度/网络抖动 | 某个问题报错或长时间无响应 | 剪掉该段，换脚本里的备选话术重录；不要在视频里出现错误页 |
| 百度 AK 日配额超限 | 网点无距离/地图 | 话术改为"从全国 800+ 网点数据库检索就近网点"，主体功能（名称/电话）不受影响 |
| 定位超时 | 一直"正在定位..." | 直接输入带地名的问题（"我在中关村..."），文本地址可解析 |
| RAG 回答太长 | 视频拖沓 | 剪辑加速等待段，每个场景只保留开头 5 秒+结尾 15 秒 |
